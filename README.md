# Тестирование сайта edujira.ifellow.ru

Проект представляет собой набор автоматизированных тестов для тестирования функционала сайта edujira.ifellow.ru. 
Автотест реализован по паттерну PageObject c использованием локаторов X-Path для выбора элементов на странице.
Каждый степ имеет проверку assert.

## Технологии

* Java
* JUnit5
* Allure
* Selenide
* Maven

## Установка

1. Склонируйте репозиторий: `git clone https://github.com/AkcentEgor/IF_Sitnikov.git`
2. Перейдите в ветку `HWF_UI`
3. Установите `maven`

## Сценарий

1. Авторизоваться в edujira.ifellow.ru
2. Перейти в проект “Test”
3. Проверить общее количество заведенных задач в проекте
4. Перейти в задачу TestSeleniumATHomework и проверить
   - "статус задачи - Сделать
   - "Исправить в версиях: - Version 2.0"
5. Создать новый баг с описанием

## Использование

Для запуска тестов выполните команду:

```
mvn clean test
```

## Просмотр отчета

Для формирования отчета используйте команду:

```
mvn allure:report  
```

Для формирования отчета его просмотра в браузере используйте команду:

```
mvn allure:serve 
```
