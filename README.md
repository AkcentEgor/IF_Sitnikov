# Тестирование работы API rickandmortyapi.com и reqres.in

Проект представляет собой набор автоматизированных тестов для тестирования функционала API ресурсов.
Автотест делает различные запросы по API и формирует отчет о выполнении в Allure.

## Технологии

* Java 17
* JUnit5
* Allure
* Selenide
* Maven
* Cucumber
* RestAssured

## Установка

1. Склонируйте репозиторий: `git clone https://github.com/AkcentEgor/IF_Sitnikov.git`
2. Перейдите в ветку `HWF_API`
3. Установите `maven`

## Тест 1

Сценарий: Проверить совпадают ли раса и местонахождение у искомого персонажа и последнего персонажа в последнем эпизоде, в котором появлялся искомый персонаж

На сайте есть документация по АPI по сериалу Рик и Морти https://rickandmortyapi.com

1. Найти информацию по персонажу "Morty Smith"
2. Получить из списка номер последнего эпизода, в котором появлялся персонаж
3. Получить последний эпизод
4. Получить из списка последнего эпизода последнего персонажа
5. Проверить, что раса и местонахождение у искомого персонажа и последнего персонажа в последнем эпизоде, в котором появлялся искомый персонаж, не совпадают

## Тест 2 

Сценарий: Проверка на создание пользователя и валидность данных

На сайте есть документация по АPI https://reqres.in/

1. Создать пользователя c данными из json файла
2. Сменить созданному пользователю имя на "Tomato" и работу на "Eat maket"
3. Получить последний эпизод
4. Отправить запрос на создание данного пользователя на сервисе reqres
5. Проверить, валидность данных пользователя

## Использование

Для запуска тестов выполните команду:

```
mvn clean test
```

## Просмотр отчета

Для формирования отчета используйте команду:

```
mvn allure:report  
```

Для формирования отчета его просмотра в браузере используйте команду:

```
mvn allure:serve 
```
